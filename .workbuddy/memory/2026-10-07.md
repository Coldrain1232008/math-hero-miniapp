# 2026-10-07

## 大会分享「让与会者现场体验」方案调研（不改代码）

背景：小程序已发布（线上名称「大星学习记录本」），个人主体。用户反馈
"只能靠搜索名称找到，拿不到二维码、也没有分享途径"，想在大会分享时
给与会者体验机会。

### 关键发现

**1. 小程序码个人主体可以生成（用户前提有误）**
微信公众平台 → 设置 → 基本设置 → 「小程序码及线下物料下载」，
可下载高清码，还能自定义中间 Logo。要求：小程序已发布（已满足）。
生成入口与主体类型无关，个人 / 个体户 / 企业一致。

**2. "没法分享"的真正原因有两个，都不是"个人主体"本身**
- **代码层：全项目未实现 `onShareAppMessage` / `onShareTimeline`**（grep 全
  miniprogram/ 为空）。不实现 `onShareTimeline` 就**一定**分享不到朋友圈。
- **资质层：未做微信认证会限制「被搜索」「被分享」能力**（微信开放社区
  多个帖子确认：个人未认证小程序正式版无法转发）。个人主体可做微信认证，
  约 30 元。→ 建议用户先到后台确认认证状态。

**3. ⭐ 最强的现场体验路径：让与会者自助"注册新班级"（完全零改代码）**
`cloudfunctions/createClass` 的邀请口令 = **任意一个已存在班级的
`teacherKey` 或 `studentKey`**。而 `studentKey`（班级密钥）本来就是发给
全班学生用的半公开信息。
→ 讲座者把自己班级的密钥当公开邀请口令说出来，与会者即可：
   扫码 → 登录页底部「还没有班级？注册一个新班级」→ 填班级名 +
   邀请口令 → 秒建一个**属于自己的班级** → 自动进入教师端。
产品里已完整做好（`login.wxml` L80-84 入口、L109-122 弹窗且界面明确写着
「填写任意一个已存在班级的密钥」）。
优点：每人独立一班互不干扰；拿到教师密钥会后还能继续用（推广加分）。
副作用：`classes` 会多出几百条测试记录，会后需用 super 后台清理。

**4. 学生账号可多人先后登录（本次新发现，注意）**
`login` 的 studentLogin 只在 `!student.openid` 时绑定 openid（L101-106），
**不校验"已绑定是否本人"**。所以一个学生账号可以被多人依次登录成功。
副作用：第一个人走完天赋测试后 `talentId` 已写入，后续人登录会直接进
角色页、跳过天赋测试。若要每人完整体验，得准备多个体验号。

**5. 批量导入体验号的格式已支持指定口令**
`importStudents` 的 `parseStudentLine` 支持 `学号 姓名 口令` 或
`学号,姓名,口令`（学号必须纯数字）。可批量做 `001 体验01 DX001` 这种表。
教师端入口：首页 → 班级管理。

## 实施：接入分享能力（用户已确认认证做完，要求改代码）

### 交付内容（commit 见下）

**好友转发** — `miniprogram/utils/share.js` 作为文案单一真源，
20 个页面统一注入 `onShareAppMessage`（`tools/add-share-hooks.js`，幂等）。
`path` 一律指向 `/pages/login/login` —— 接收者多半没账号，落到功能页会卡住，
落到登录页才有「注册新班级」的出路。

**分享封面图** — `miniprogram/images/share-cover.png`（800×640，5:4，64KB），
生成脚本 `tools/gen-share-cover.py`（PIL + Hiragino Sans GB，2 倍超采样后 LANCZOS 缩）。
改文案重跑脚本即可。

**朋友圈** — ⚠️ **只在登录页暴露 `onShareTimeline`**，这是本次最重要的决策：
- 朋友圈打开的是「单页模式」：**无登录态 + 禁止任何页面跳转**（官方文档确认）
- 学生端/教师端页面都依赖 `globalData`，那种环境下渲染不出来；
  连项目里 4 个页面已有的「未登录 reLaunch 登录页」兜底也**跳不走**（跳转被禁）
- 所以分享出去只会白屏 → 不给它们暴露入口，避免更差体验
- 登录页做了单页模式适配：检测 `scene === 1154` → 切成纯静态介绍视图，
  **不调用任何云函数**（单页模式用云开发要另开「未登录访问」，避开它）
- 微信硬规则：**页面要启用朋友圈分享必须同时定义两个钩子**，
  缺任何一个入口都不渲染**且不报错**（静默失败，极难查）
- `tools/trim-timeline-hooks.js` 是收敛入口时的一次性清理脚本

**小程序码** — 新增 `cloudfunctions/getShareCode`：
- 云调用 `cloud.openapi.wxacode.getUnlimited`，免维护 access_token
- ⚠️ `config.json` 声明 `permissions.openapi`，**必须与 index.js 一起上传**
  （漏传报 errCode -604100「权限不足」）
- `scene` 限制 `^[A-Za-z0-9_-]{1,32}$`：微信不支持 `%`，中文无法 urlencode
- 码写入云存储固定路径 `share-codes/invite.png`（覆盖式，不堆积），
  返回 `cloud://` 供 `<image>` 直接渲染，无需换临时链接
- 登录页加「邀请同行 · 出示小程序码」入口，`show-menu-by-longpress` 支持长按识别，
  另有「保存到相册」按钮（需 `scope.writePhotosAlbum` 授权，已做拒绝兜底）

### 经济闭环
```
super 充值 → wallets → 教师 grant → students.coins
商城出口：虚拟品 burn → wallets.totalBurned（销毁防通胀）
         实物品 refund → 回流 wallets.balance/totalRecycled（补偿采购）
守恒式：totalRecharged = studentCoins + walletBalance + totalBurned
```
`superAdmin` dashboard 的 overview 加上 `totalBurned`，super 页总览加一格「商城销毁」，
守恒校验文案同步更新。

   整个事务回滚 → 事务外先 `ensureWallet` 补建。原注释写反了

## 班级注册审核 + 密钥自定义修改

### 需求（马老师提出）
1. 注册班级无任何审核，谁都能建 → 必须填写**邀请口令**（已存在班级的教师密钥或班级密钥）验证
2. 班级密钥 / 教师密钥生成后无法改 → 教师端要能改成自己喜欢的，且**全局查重不能与已有班级撞车**

### 实现
- **`createClass/index.js`（重写）**：接收 `{ className, inviteKey }`。先 `classes.count()`，若为 0（全系统第一个班，冷启动）免邀请口令；否则用邀请口令依次匹配 `teacherKey`、`studentKey`，都找不到就报错「邀请口令无效」。创建时写入 `invitedBy` / `inviterName` 便于追溯。
- **`updateClassKeys/index.js`（新增）**：一个云函数两种模式，`action:'check'` 只查重不落库（供输入框实时提示），`action:'update'` 校验后写入。
  - 密钥规则放宽为 `/^[A-Z0-9]{4,12}$/`（不再强制 T/S 前缀，允许老师自定义），统一转大写
  - 查重同时比对 `teacherKey` 和 `studentKey` 两个字段，且**排除自己**（避免「原值不变」被误判冲突）
  - 与原值相同返回 `{ success:true, unchanged:true }`
- **登录页 login.wxml/js**：注册弹窗增加「邀请口令」输入框（`onInviteKeyInput`），提交前非空校验
- **教师端 teacher-class 页面**：两个密钥后各加「修改」按钮（`openKeyEdit`），弹窗内含当前值展示、新密钥输入、实时查重状态条（⏳检查中 / ✅可以使用 / ❌已被占用 / ⚠️相同），保存前二次确认并提示旧密钥失效
  - 前端输入先本地正则校验，通过后 **500ms 防抖**再调云函数查重（`this._keyCheckTimer`）
  - 粘贴后直接点保存也会先补一次查重
